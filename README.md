# 🚀 FadhlaouiStack

**FadhlaouiStack** is a full-stack AI-powered website builder that allows users to generate and publish complete websites using natural language prompts. It integrates OpenAI's ChatGPT to create HTML/CSS/JS code dynamically and supports instant previews and one-click deployment.

---

## ✨ Features

- 🔮 **AI-Powered Site Generation** – Describe your idea, and ChatGPT builds the site for you.
- ⚡ **Live Preview** – Instantly preview generated code in the browser.
- 🛠️ **Editable Output** – View and customize code before publishing.
- 🌍 **One-Click Publishing** – Deploy your site to the web with ease.
- 🔐 **User Authentication (optional)** – Save and manage your sites securely.

---

## 🧱 Tech Stack

| Layer        | Tech                         |
|-------------|------------------------------|
| Backend      | [create-express-node-starter](https://www.npmjs.com/package/create-express-node-starter), Node.js, OpenAI API |
| Frontend     | React, TailwindCSS           |
| Deployment   | Vercel, Netlify (or custom)  |
| Editor       | Sandbox iframe or Monaco     |
| Auth (optional) | Firebase/Auth0/Clerk       |

> ✅ The backend is built using [create-express-node-starter](https://www.npmjs.com/package/create-express-node-starter) – a REST API boilerplate for Express.js and MongoDB, created by Raed Fadhlaoui.
